# Material candidate self-review

This is a self-review, not the independent external review required for final acceptance.

The exact two-file foundation diff preserves task admission identity, task-owned execution cancellation, explicit stop evidence and resource ownership. Creation intent remains durable before Git effects; moving the hook outside administration does not mark its task idle. Stable collection receives a new workspace view rather than mutating the execution signal or claiming stopped success.

Internal observation code keeps Git commits separate from sampled bytes, verifies blob byte identity after the existing string-returning Git helper, rejects symlink traversal, holds/rechecks descriptors, bounds reads, and retains UTF-8 ranges. Matching does not use line-number equality as identity, expand types, or infer behavioral compatibility. Duplicate declaration correspondence remains ambiguous. Reports escape control characters and retain independent endpoints; they do not reveal digest-only bodies/default values. Parser-side masking is still unimplemented.

During review, the matcher was changed from repeated scans of overload groups to signature buckets. Coverage now remains incomplete for missing header/body/remainder evidence. A test initially attempted to mutate a frozen comparison result; it was corrected to mutate the input before comparison, retaining the immutability invariant. Report generation is byte-bounded before accumulating further entries, and page checking also counts JSON escaping. A capture from a repository subdirectory is rejected rather than treating its relative paths as repository-root paths.

Outstanding proof remains explicit: captured working files are not atomic whole-workspace snapshots; malicious same-user programs are outside the security boundary; parser/helper/transport/source masking is not qualified; complete pinned static/application tests and independent review remain blocked. No observation failure is wired to cancel inference because these internal observation components are not yet connected to execution.
