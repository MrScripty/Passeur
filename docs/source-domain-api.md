# Source-domain API

`compareCapturedSources(input, observed, dialect, extractor)` in `src/observation/comparison.ts` is the small service-free entry point for an ordinary caller. It returns both structured extractions and their structural comparison. Each extraction carries the exact source reference and content hash, dialect, parser and extractor identities, coverage, limitations, declarations, UTF-8 byte ranges, and each declaration's `enclosing` containment path. The comparison reports correspondence and syntax-level changes. It makes no task attribution, authorship, semantic compatibility, or merge-safety claim.

Supply already captured `SourceFile` values. `captureWorkingFile` and `readCommittedFile` own repository capture and source identity; callers must retain the returned captures rather than reconstructing content from a later path read. The same repository, path, dialect, parser, and extractor contract is required for comparison. A missing or unsupported source yields explicit unavailable or incomplete coverage. Invalid pairs and contradictory ranges throw `BridgeError` with structural diagnostic codes.

For production resource isolation, pass an owned `NativeAnalysisHelper` as the extractor and call `await helper.close()` during caller shutdown. The helper bounds its queue, child runtime, memory, and cache. Direct `extractNativeFunctions` is suitable for isolated local analysis where the caller owns its parser execution and resource limits. Neither entry point starts a repository service, MCP server, coordinator, or model.

`selectPeerOverlapEvidence` consumes captured source and trusted comparison facts after the caller has established source permission. Its result is a deterministic, versioned source-evidence value, **not an authorization grant**. It includes separate input and observed declaration summaries and byte-addressed excerpts. Each excerpt has a source side, reason, and `omitted_before`/`omitted_after` markers relative to its declaration; disjoint excerpts must never be joined as adjacent source. A caller that publishes or expands excerpts must recheck its current source authority: the existing grant for parent reads or the exact selected-case/task authority for worker delivery and detail. Missing captures, missing declaration facts, and exhausted budgets remain explicit in `coverage` and `limitations`.

The selector measures the UTF-8 bytes of the complete JSON evidence value, including escaped text and its content ID. When excerpts exceed the selected budget, it retains complete before/after pairs in stable observation order, sets `coverage: "incomplete"`, and adds `evidence_budget_exceeded`. If required metadata alone exceeds the budget, it raises `STRUCTURAL_OVERLAP_INVALID`. Header-only edits use local changed windows. A shared unchanged line may separate two distant body edits into distinct windows; callers must request authorized detail when the selected windows or an incomplete result omit context needed for a decision. This selector's byte limit does not account for the surrounding worker-delivery envelope.

The focused non-agent example is `tests/native/source-domain-consumer.test.mjs`; the excerpt contract is exercised in `tests/core/peer-handoff-evidence.test.mjs`.
