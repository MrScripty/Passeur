## Required sequence

Run the full pinned checkout commands: `npm ci`, `npm run check`, `npm test`, `npm run build:runtime`. Test the built artifact without the source checkout, on the target Linux/local filesystem with flock. `npm run probe:service -- --project ABSOLUTE_PROJECT --profile ABSOLUTE_PROFILE --state-root ABSOLUTE_STATE --runtime ABSOLUTE_INSTALLED_CLI --yes` is an opt-in preparation-only two-client probe; it starts no inference and cannot prove human permission or native agent behavior.

Update existing named installed registrations through the established authority/backup workflow. In two real Codex sessions, verify status2 and the exact same service generation. Use different linked worktrees and verify that reviews use the correct source view. Submit independent Muse/Codex assignments with unique keys; end one wait and then one client. Prove actual work continues, the other client is unaffected, and a new client can human-adopt the original task by ID/key without replay.

Exercise a question after a completed native turn, a native permission prompt, explicit denial, dismissed presentation, long unanswered input, and an input/cancel race. A factual answer cannot grant permission. Record the actual host Stop behavior: stopping a wait is not task cancellation. Use the explicit cancel tool and observe real descendant termination or truthful uncertainty.

Prove long silent work, long native subprocesses and Git hooks, including durations beyond the removed limits. Fake clock tests establish the bridge's timer logic only. Verify Muse's pinned exit/fold APIs, view-gap handling, in-progress item settlement, native in-turn user-input support and possible SDK-internal deadlines. Qualify or explicitly remove unsupported native variants; do not advertise comprehensive Muse input support from completed-turn question tests alone.

Pause the real service, race new clients, kill only discard-authorized synthetic fixture processes, and verify ownership/recovery. Parent loss with surviving descendants must not allow unsafe task replay or resource deletion. Check interruption during task/answer/result publication and the corresponding explicit reconciliation paths.

Confirm profile1/2 migration and unchanged historical bytes, named required/optional/permission settings, incompatible-service refusal, and installed dependency closure. Complete independent external review of the material candidate and fresh-session application of the adapter skill. Preserve exact protected commit OIDs and terminal resource dispositions.

Record exact Node/Git/flock/OS/filesystem, MCP SDK, Muse SDK/CLI, Codex CLI, installed build and host versions. Mark each scenario passed/failed/blocked with its actual environment, not an aggregate certificate. Only the plan's complete required claim set permits Accepted.
