# Passeur setup

The current procedure is [Startup and installation](startup-and-installation.md). It replaces checkout-bound registration and configuration-presence-only verification.

Use explicit server names and version-specific installed runtimes. Registration is distinct from direct transport verification, repository coordination readiness and actual Codex/Muse workflow acceptance. Keep personal-configuration and live-account changes explicitly authorized.

For operator acceptance, follow [Installed-host acceptance](installed-acceptance.md). For implementation verification status, read the [evidence report](plans/discoverable-startup-and-installed-runtime/reports/implementation-evidence.md).
